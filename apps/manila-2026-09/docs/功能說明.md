# 馬尼拉三日 — 功能說明

這是給這次同行團員用的三日行程網頁（可加到手機主畫面），不是公開旅遊網站。

**網址：** https://manila-2026-09.pages.dev  
請用手機 Safari（iPhone）或 Chrome（Android）打開。不要用 LINE 內建瀏覽器。

## 怎麼進去

不用註冊。打開就會看到角色牆，點你的頭像，確認後進入。  
選錯了就到首頁左上角「登出重選」。已被 CHECKED IN 的頭像別人不能再點，直到那人登出。

**登出不會刪資料。** 只是把座位空出來，方便換手機或選錯人。同一個頭像永遠是同一組帳，再點進去會接續剛才的記帳、必買勾選、願望、猜人、醜照、正式抽籤。公帳與公開必買本來就是全團一份，誰登入都看得到。訪客抽籤是體驗、不寫進正式配對，登出後可能再看一次動畫。

可選身分：

- **正式團員：** 美慧、智濠、法蓉、子晨、峻軒、韋劭、郁欣、承宏。一人一個。
- **訪客獨占：** 彥文、靜瑩、宇庭、庭宇。一人一張。
- **共用訪客：** 一次一位，沒有照片（白邊圓形字）。

Haru 不在選角牆。

正式團員可以記帳、勾必買、玩任務（抽籤、願望、猜人、傳醜照）。  
訪客全站只能看；任務抽籤是體驗（天使和惡魔都是你自己），不會佔正式抽籤。

## 攻略要注意

- 景點名稱、說明、時間、位置、照片：全團同一份。
- 首頁「集合點」全團都看得到；正式團員可改，訪客只能看。
- 攻略頁「收藏文章」全團都看得到；正式團員可新增，誰加的誰可以刪。
- 攻略頁／首頁「必買」可選公開或只有自己看。點一下可劃掉，勾選狀態每人一份。

## 任務

正式團員抽一次籤，之後可看自己的天使／惡魔、填一次願望、猜人、幫惡魔傳醜照。  
完整配對在行程最後一天中午 12:00（馬尼拉時間，約 2026/9/27）才公布。請不要在群組爆雷。

訪客抽籤結果不會存進正式配對。
