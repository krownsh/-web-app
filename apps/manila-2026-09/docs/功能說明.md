# 馬尼拉三日 — 功能說明

這是給這次同行團員用的三日行程網頁（可加到手機主畫面），不是公開旅遊網站。

**網址：** https://manila-2026-09.pages.dev  
請用手機 Safari（iPhone）或 Chrome（Android）打開。不要用 LINE 內建瀏覽器。

## 怎麼進去

1. 自己註冊一組帳號（用你常用的 email）。
2. 登入後會自動加入這團，**不用團碼**。
3. 先選「你是誰」。**選完不能改。**

可選身分：

- **正式團員（九人裡的八位）：** 美慧、智濠、法蓉、子晨、峻軒、韋劭、郁欣、承宏。一人一個，選走就不能再選。
- **訪客獨占：** 彥文、靜瑩、宇庭、庭宇。一人一張。
- **共用訪客：** 可多人同時用，沒有照片（選角列在正式團員後面，白邊圓形字）。

正式團員可以記帳、勾必買、玩任務（抽籤、願望、猜人、傳醜照）。  
訪客全站只能看；任務抽籤是體驗（天使和惡魔都是你自己），不會佔正式九人、也不會寫進正式抽籤。

## 分頁

| 分頁 | 做什麼 |
| --- | --- |
| 首頁 | 倒數、下一個行程、團員航班、必買清單、天氣匯率 |
| 行程 | 三日時間軸 |
| 記帳 | 公帳／私帳 |
| 攻略 | 各景點說明、收藏文章、必買 |
| 任務 | 天使與惡魔 |
| 提醒／行前 | 注意事項與出發前清單 |

## 攻略要注意

- 景點名稱、說明、時間、位置、照片：全團同一份。
- 你在攻略頁**自己加**的文章連結或必買：只存在這支手機，別人看不到，換手機也沒有。
- 在**首頁**新增的必買才會上雲端（可選公開或只有自己看）。勾選狀態每人一份。

## 任務

正式團員抽一次籤，之後可看自己的天使／惡魔、填一次願望、猜人、幫惡魔傳醜照。  
完整配對在行程最後一天中午 12:00（馬尼拉時間，約 2026/9/27）才公布。請不要在群組爆雷。

訪客抽籤結果不會存進正式配對。
