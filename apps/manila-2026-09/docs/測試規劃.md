# 馬尼拉三日 — 外部測試

**網址：** https://manila-2026-09.pages.dev  
自己註冊，不用團碼。建議人數：至少 2 位正式團員、2 位獨占訪客、2 位共用訪客。用真的手機測。

測完請把異常（哪一頁、做了什麼、預期／實際）傳給主揪。不要在群組公布你抽到的天使／惡魔。

## 進場

- [ ] iPhone 用 Safari、Android 用 Chrome 打開（不要用 LINE 內建瀏覽器）
- [ ] 可加入主畫面，圖示名稱為「馬尼拉三日」
- [ ] 註冊／登入後點一次「進入」就到選角，沒有輸入團碼的畫面
- [ ] 選角後再登出登入，身分還在、不必重選

## 選角

- [ ] 點正式團員頭像會先出現確認身分畫面，按「我知道了」才鎖定
- [ ] 正式 A 選走一位後，正式 B 看不到那位（已 check in）
- [ ] 獨占訪客被選走後，別人不能再選同一張
- [ ] 共用訪客可以多人同時選
- [ ] 選錯不能自行更改（請另開帳或找主揪）

## 正式團員

- [ ] 任務抽籤影片左右角色沒被裁掉
- [ ] 抽完可再進任務看到結果
- [ ] 可填願望（每人一次）、猜人、上傳醜照；燈箱照片置中
- [ ] 記帳可新增一筆公帳、一筆私帳
- [ ] 首頁新增公開必買，另一位正式團員看得到
- [ ] 攻略頁看得到同一套景點說明；你在攻略頁加的連結，另一位正式團員也看得到
- [ ] 攻略必買可劃掉；公開項目另一位正式團員看得到，私人項目看不到

## 訪客

- [ ] 抽籤後天使／惡魔都是自己
- [ ] 沒有填願望、猜人、上傳醜照的按鈕
- [ ] 記帳只能看、不能新增
- [ ] 攻略／行程可看
